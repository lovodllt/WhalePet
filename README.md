# Dworld 桌面伙伴

Linux 首发的桌面端，连接 Dworld 中同一个人物，支持多屏观察、文字与两种语音输入。当前直接使用 GPT 宠物库中“deepseek酱”的原始透明动作素材，Live2D 尚未接入。

当前为开发预览版，尚未产出便携安装包或完成真实多屏与语音设备验收。

## 启动

Linux 下运行 `./start.sh`，`./start.sh --preview` 只预览界面，不读屏幕、不启用麦克风，也不调用人物模型。

其他机器先在本目录运行 `npm ci`。Python 需能够导入相邻的 `virtual_character` 包及其依赖；语音沿用 Dworld 已安装的识别模型与合成服务。Wayland 采集还需系统 Python 的 PyGObject、GStreamer 和 PipeWire 插件。Linux 窗口当前使用 X11 或 Xwayland；Wayland 会话通过系统屏幕共享接口采集。Windows、macOS 和原生 Wayland 窗口尚未验收。

## 使用

- 平时只显示人物；右键人物，或聚焦后按 Enter / Space，展开环绕的聊天、允许观察、持续听、自由移动和设置按钮。再次右键、按 Esc 或切换到其他窗口可收起。设置会在独立、可调整大小的系统窗口中打开。
- 点击人物立即招手；开启自由移动时，如果她当前方便行动，会立即向桌面上的任意方向走一段，之后间歇移动。关闭自由移动会立刻停下。接近屏幕边缘时她会向内走。
- 按住人物移动时播放提起姿态和摆动，松开后播放放下反馈；拖动不会误打开快捷菜单。
- 对白使用人物头顶的漫画气泡，位置随大小调整；长内容可滚动，双击气泡打开聊天。
- Enter 发送，Shift 加 Enter 换行。右键展开快捷按钮，动作和管理功能位于设置的“互动”页。
- “录音”按钮开始与结束一次录音；“持续听”开启免唤醒词收音，再次点击停止。
- “允许观察”是开关：关闭时停止观察并盖上钢盆；开启只建立共享，不立刻分析，之后按设定间隔观察。设置中也可切换。
- 盖上的盆会跟随人物各动画帧的头部位置移动和倾斜。
- Wayland 下，开启观察时需在系统窗口选择全部屏幕；授权的共享会话保持期间，后续定时观察复用同一会话。停止观察、隐藏、锁屏或退出会结束共享；恢复后需要再次开启观察，不会在后台反复弹窗。共享开启期间系统显示共享状态，视频帧在本机持续流动，仅按设置的间隔取样交给人物处理。
- 取画面时会短暂隐藏桌宠内容以免遮挡，窗口本身保持打开，减少反复显示窗口可能引发的系统启动提示。
- 设置中分别调整两种模式的观察间隔与发言最小间隔，以及大小、音量和输入输出设备。
- 设置中的人物大小滑块支持 50%–180%，拖动时预览、松开即保存，下次启动沿用。
- 设置中的“互动”可选招手、小跳、探头、轻摆和欠身，并可找回、隐藏和退出桌宠。设置按外观、陪伴、语音、互动分组，支持浅深色与减少动态。
- 隐藏会暂停本机观察与收音；通过托盘恢复。设置的互动页与托盘菜单可重启，重启会结束当前屏幕共享。退出只关闭桌宠。

用户从桌面发起的聊天在桌面继续。人物自主发起时，屏幕话题走桌面，其余仍由原后台走微信。文字留言遵循人物当前作息，不会自动叫醒她。

屏幕内容作为陪伴聊天的背景，不默认把窗口和布局逐项汇报；有想法时自然接话，也可以安静。用户明确要求描述或读取屏幕时，按具体问题回答。

允许观察时，桌面文字消息会尝试先读取新画面；如果正在观察或读取失败，消息仍会送达，不把旧画面当作当前画面。语音暂沿用最近一次观察结果。

## 后端边界

`bridge.py` 是由桌面主进程启动的私有标准输入输出连接，没有新增公网监听。它使用原配置和人物状态，但不启动生活时钟或微信发送器，也不修改原配置。

## Windows 私有连接试用

Linux 的 `start-link.sh` 启动一个仅监听本机的桌宠连接服务，用户态 Tailscale 将私网访问转发到它。连接配置位于 Linux 私有目录 `data/production/desktop-link/remote-link.json`，含密钥，不得公开分享或放入源码包。两台设备需加入同一 Tailscale 网络；通信在 Tailscale 隧道中加密，并额外验证密钥。服务每次只接受一个远程桌宠。

Windows 安装 Tailscale 和 Node.js 22.12 或更高版本后，双击 `install-windows.cmd` 安装依赖，再双击 `preview-windows.cmd` 可离线预览。要连接人物，将 Linux 上的配置文件通过安全渠道放入 `%APPDATA%\dworld-desktop-pet\remote-link.json`（目录不存在时先创建），然后双击 `start-windows.cmd`。Linux 的连接服务需保持运行；它目前不会随系统自动启动。命令行也可用 `npm ci`、`npx --no-install install-electron` 和 `npm run start:remote`。

本次只转发人物当前作息状态、用户输入的文字、人物文字回复及必要的确认，不发送屏幕或音频。Windows 远程观察、语音、完整网页活动动作同步及跨设备真实网络验证尚未完成。断线后自动尝试重连；断线期间提交的消息不会自动重发。请勿对外公开连接文件。

新代码在 `virtual_character/desktop_pet.py`。桌面出站复用现有 `voice_call` 保留通道，因此已经运行的微信发送器也会跳过它；桌面会话、主动屏幕交流与用户回复另有来源标记。气泡显示与音频播放分别记回执。

屏幕原图只在受控临时目录存在，视觉请求结束后删除；模型任务仅保存来源、摘要和用量，不保存图像或图片编码。麦克风数据通过进程管道传给现有识别器；自身声音通过浏览器回声消除处理，实机插话和回声效果仍需按实际设备验收。

## 素材与验证

`assets/ds-pet-sprites.png` 是用户现有 GPT 宠物“deepseek酱”的原始图集，稳定 ID 为 `pet_6ad3b4ca610081919d1e289803c71ecc`；来源、尺寸和 SHA256 见 `assets/character-source.json`。图集为 1536×1872 RGBA，8 列、9 行，每帧 192×208。`assets/character.png` 直接取原图首帧作为启动图标。

`sprites.mjs` 播放原有待机、左右移动、招手、失败、等待、工作和查看动作。点击立即播放原始招手帧；行走使用左右方向的八帧，停止后恢复站姿；上下移动暂时沿用左右行走帧，原素材没有正背面行走帧。拖动使用原图中一幅合适的姿态，统一倍率并对齐头部位置，配合连续摆动，避免在跳跃姿势间突变；落地恢复待机基准帧。小跳、探头、轻摆、欠身仍以基准帧做位移与旋转，用户缩放与动作分离。原素材没有专门的逐帧悬提动作，完整肢体过渡和 Live2D 仍需后续制作。

隔离验证入口：

```bash
python3 -m unittest discover -s tests -p test_desktop_pet.py -v
```

该命令从 Dworld 项目目录运行。桌面目录使用 `npm test` 检查屏幕对应、覆盖不足反馈、位置找回和设置。运行检查不应转成真实微信发送或长时间生活试验。
